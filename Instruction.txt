How to Run the Project

Option 1: Run using TestNG (Recommended)

1. Import the project as a Maven Project.
2. Right-click the project → Maven → Update Project.
3. Ensure all Maven dependencies are downloaded successfully.
4. Right-click testng.xml. 
5. Right-click testng.xml → Run As → Run Configurations.
6. In the Arguments tab, add the following VM arguments:

--add-opens java.base/java.util=ALL-UNNAMED
--add-opens java.base/java.lang.reflect=ALL-UNNAMED
--add-opens java.base/java.text=ALL-UNNAMED
--add-opens java.desktop/java.awt.font=ALL-UNNAMED

7. Click Apply and then Run.

This will execute both the API and UI scenarios and generate the reports.

Option 2: Run using Maven

Open Command Prompt in the project root directory and run:

mvn clean test

This command will:
- Clean the previous build.
- Compile the project.
- Execute all TestNG/Cucumber tests.
- Generate the TestNG and Cucumber reports.
Note:When running with "mvn clean test", these JVM arguments are already configured in the Maven Surefire plugin, so no additional VM arguments are required.

Prerequisites
